## 🚀 Commandes Utiles & Mémo

### Synchronisation Git (Push)

- **GitHub (Principal)** :
  ```bash
  git push
  ```
- **Bitbucket (Miroir optionnel)** :
  ```bash
  git push bitbucket main
  ```

### Assistant IA (Antigravity)

- **Mémorisation de règles** : tapez `/learn` dans le chat de l'assistant après une correction ou une nouvelle décision de conception pour l'ancrer durablement dans les règles d'agents (`.agents/AGENTS.md`).
